maiko automation tools

個人の作業を自動化するための、自分専用のツール群です。一般公開・配布はしていません。

できること

  • 特定の差出人からのメールを読み取り、内容に応じて Google ToDo リストにタスクを作成する
  • スプレッドシートに記録された作業ログを読み取り、時間を集計する
  • 集計結果をスプレッドシートに書き戻す
  • 予約サイトから取得した予約情報を、本人のGoogleカレンダーに登録・更新する

アプリ

  • libraryautomation — 図書館の貸出・取り置き管理の自動化

動作環境

作者本人の PC 上でのみ動作します。サーバーで常時稼働するサービスではなく、取得したデータが本人の PC の外に出ることはありません。

プライバシー

取り扱う情報とその範囲は プライバシーポリシー に記載しています。

ソースコードは GitHub で管理しています。
